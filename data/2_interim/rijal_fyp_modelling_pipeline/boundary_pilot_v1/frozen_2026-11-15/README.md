# Frozen Taqrīb Boundary Annotations v1

This is the user-approved freeze of the 25-case AI-assisted textual-boundary pilot. The dated reviewer submission and pre-freeze corrected versions remain unchanged.

- `TAQRIB_BOUNDARY_ANNOTATIONS_FROZEN_V1.csv` is the frozen table.
- `FREEZE_MANIFEST.json` records authorization, inputs, output hash, and limits.
- `FREEZE_MANIFEST.sha256` contains the manifest checksum.

The freeze records boundary and role annotations only. No ranks were assigned, and uncertain spans remain uncertain. The confidence field maps the original reviewer self-rating of 100% to `high` after user approval; this is not calibrated probability or independent validation.
