# Excel-compatible CSV copies

These files are copies of the UTF-8 source CSVs with a UTF-8 byte-order mark (BOM), so Excel can detect Arabic text when opening the CSV. Cell values and row ordering were round-trip checked against the source files. The original CSVs in the parent directory remain unchanged.

Use these copies for spreadsheet viewing. The internal sample key is still an audit file; it is no longer blinded after all three first-pass reviews have been saved.
