# Literature Review

## Purpose

Build an evidence-based account of the research problem, relevant classical rijāl scholarship, computational Arabic NLP, evaluative stance analysis, narrator identity resolution, graph learning, and evaluation methodology.

## Search record

For every search, record:
- date and database / search engine;
- exact query and filters;
- inclusion and exclusion criteria;
- number of records retrieved, screened, and retained;
- reasons for exclusion.

## Literature register

Use one row per publication in a spreadsheet or CSV with fields such as:
`paper_id,title,authors,year,venue,doi_or_url,research_question,data,method,findings,limitations,relevance,quality_notes`.

## Critical synthesis

Do not write a sequence of paper summaries. Compare assumptions, datasets, operational definitions, methods, evidence, and limitations. Identify what remains unresolved and how the present study will address it.

## Research integrity

Distinguish peer-reviewed publications, preprints, technical reports, documentation, and informal web pages. Verify bibliographic details against publisher or repository records.
