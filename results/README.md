# Results and Analysis

Store result tables, figures, error analyses, and interpretation here. Keep raw experiment outputs separate from manually edited reporting artefacts.

For each result, link to:
- experiment ID and configuration;
- dataset version and split;
- code commit;
- evaluation script version;
- metric definitions;
- relevant uncertainty and limitations.

Do not report a metric without enough information to reproduce how it was calculated. Distinguish exploratory findings from confirmatory results. Never present zero eligible records, failed identity resolution, or missing data as positive model evidence.
