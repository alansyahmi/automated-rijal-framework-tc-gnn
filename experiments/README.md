# Experiments

No experiment should be considered confirmatory until its data snapshot, target, split design, baseline, metric, and configuration are documented.

## Experiment record template

- Experiment ID:
- Date:
- Research question / objective:
- Dataset version and checksum:
- Prediction unit and target:
- Inclusion / exclusion rules:
- Train / validation / test split and split unit:
- Leakage checks:
- Baseline / model:
- Input modalities:
- Preprocessing:
- Hyperparameters:
- Random seed(s):
- Software and hardware environment:
- Primary and secondary metrics:
- Results location:
- Deviations from plan:
- Interpretation and limitations:

## Minimum reporting

Report class counts, per-class precision / recall / F1, Macro-F1 where appropriate, confusion matrix, model-selection procedure, and error analysis. Record unsuccessful runs and deviations rather than deleting them.
